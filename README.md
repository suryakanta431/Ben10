# 👽 Ben 10 Classic Universe Game

An AAA-inspired action game project based on the classic **Ben 10 Universe**, where players can transform into powerful aliens using the Omnitrix and explore immersive gameplay mechanics inspired by the original series.

> ⚠️ This project is currently under development.  
> The core transformation system has been completed, while combat systems, additional aliens, enemies, and story content are still in progress.

---

# 🎮 Game Overview

This project focuses on recreating the feeling of the original Ben 10 Classic universe with modern gameplay systems, cinematic visuals, and smooth alien transformation mechanics.

Players can:
- Transform into different aliens
- Use unique movement abilities
- Explore immersive environments
- Experience AAA-inspired gameplay systems
- Switch between alien forms in real time
